# stock-prediction-using-LSTM
This project focuses on predicting stock prices using an LSTM (Long Short-Term Memory) neural network. LSTM is a type of Recurrent Neural Network (RNN) capable of learning long-term dependencies, making it well-suited for time-series forecasting tasks like stock market prediction. The model is trained on historical stock data, where it learns patterns and trends in price movements to make accurate future predictions. The project includes data preprocessing, normalization, model training, and visualization of results, allowing a clear comparison between actual and predicted stock prices. It demonstrates how deep learning techniques can be applied to financial data analysis and forecasting using Python and TensorFlow.
